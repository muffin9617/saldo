## 数据安全与兼容

迁移只增加 cards.entitlements、subscriptions.cycle_exact/cycle_anchor、saldo_ledger_events 与 saldo_ledger_write 事务 RPC；无历史数据 UPDATE、DELETE 或费用补推。旧余额只在读取时适配成金额权益；旧快照继续展示为快照，不算付款或消费；只在用户后续记录动作时保存新结构。元数据编辑不改余额或快照。

RLS 限制账号拥有的数据；RPC 使用 SECURITY INVOKER、限定 search_path、锁定单条记录并检查版本；付款和权益动作在同一事务提交。过期版本、超额消费或无效金额失败会回滚。永久删除只能作用于已移除记录。

发布 dist 不含演算账号、fixtures、重置工具、真实样本或服务端密钥。prototype 仅作为隔离设计源码保留，未被静态资源路径引用。
