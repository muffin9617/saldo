# Saldo 交互约定（2026-11-20）

- 四个主 Tab 保留各自搜索、排序和滚动位置。详情、我的二级页和弹层进入浏览器历史；按钮、左滑快捷方式、浏览器/Android 返回共享层级与未保存保护。左滑返回保留现有产品约定，系统屏幕边缘留给平台手势。
- 编辑入口靠近记录名称。新建与编辑共用整页字段、校验、底部取消/保存栏、键盘避让及一次写入；新建类型切换和离开页面前确认有改动的草稿。
- 提醒时间先写入整页草稿，最终保存才提交。余额历史只读，编辑时隐藏移除记录操作。版本冲突保留草稿并要求核对最新值。
- 小选择与安装指引使用弹层，永久删除保留确认。弹层有可访问标题，初始焦点根据内容确定，关闭后回到原控件或合理替代控件。复杂长表单使用页面。
- 保存成功短提示；保存失败在页面持续显示，保留输入并可重试。离线明确标示，禁止将未提交内容描述为已保存；当前草稿只保留在页面内存，刷新/关闭会提示，不提供离线自动同步。
- 移除记录提供 10 秒撤销；永久删除无撤销并明确说明影响。撤销仍使用版本校验，不能覆盖其他设备的修改。
- 核心触控控件以至少 44px 高作为产品目标，焦点样式可见；Toast 使用屏幕阅读器状态播报。维持放大、减少动效和增强对比度支持。
- 不把单次推送服务接受请求表述为用户已收到；通知偏好保存与系统授权是两个明确动作。

验证使用隔离的本地模拟账号及记录，不修改生产 Supabase、每日调度或发送真实邮件/推送。本轮完整系统交互脚本覆盖原生 Back/Forward、URL/刷新、Tab 状态、草稿、新建、离线重试及撤销。
